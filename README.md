# Prime Lens

Aplicação web interativa que simula um scanner inteligente de código via câmera com IA, desenvolvida como projeto acadêmico da disciplina de Web Development.

## Tecnologias

- HTML5
- CSS
- JavaScript

## Funcionalidades

- Login com validação de formulário
- Prompt de boas-vindas e alert de confirmação
- Slideshow automático com navegação manual (botões e dots)
- Protótipo interativo de câmera com IA simulada
- Tema claro/escuro
- Scroll reveal animado nas seções
- Cópia de código para área de transferência

## Como rodar

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no VS Code.
